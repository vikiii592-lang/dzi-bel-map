# ДЗИ по БЕЛ — 86 училища

Интерактивна карта на 86 училища със среден успех под 3,00 на ДЗИ по БЕЛ през всяка от годините 2024, 2025 и 2026.

Статични HTML, CSS и JavaScript файлове. Училищните имена, адреси и резултати са запазени от предоставените данни. Leaflet и MarkerCluster са включени локално; картографската основа е OpenStreetMap.
